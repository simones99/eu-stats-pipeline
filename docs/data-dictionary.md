# Data dictionary

Generated by `eustats report` from the dbt project. Marts are the tables meant for analysis; staging models are typed views over the raw files.

## `marts.dim_geo`

Geographic units found in the data, classified by level and EU membership.

| Column | Type | Description |
|---|---|---|
| `geo` | VARCHAR | Eurostat GEO code. |
| `geo_label` | VARCHAR | English label from the Eurostat GEO codelist. |
| `geo_level` | VARCHAR | eu_aggregate, country, nuts1, nuts2, nuts3 or other_aggregate. |
| `country_code` | VARCHAR | Two-letter country code for countries and NUTS regions. |
| `is_eu27` | BOOLEAN | True for the 27 Member States and their regions. |
| `is_non_regional` | BOOLEAN | True for extra-regio (code ending in Z/ZZ) and not regionalised (X/XX) units. |
| `in_gisco_nuts2024` | BOOLEAN | True when the code has a NUTS 2024 level-2 geometry in GISCO. |

## `marts.fct_indicator_values`

Analysis-ready observations for the EU27 aggregate, the 27 Member States and their NUTS 1 and NUTS 2 regions (non-regional units and NUTS 3 regions excluded; regions from older NUTS versions kept and marked by in_gisco_nuts2024). One row per indicator, geo and year.

| Column | Type | Description |
|---|---|---|
| `indicator_id` | VARCHAR | Indicator identifier. |
| `geo` | VARCHAR | Eurostat GEO code. |
| `geo_level` | VARCHAR | Level of the geographic unit. |
| `country_code` | VARCHAR | Two-letter country code (null for the EU aggregate). |
| `in_gisco_nuts2024` | BOOLEAN | True when the region exists in NUTS 2024; false for codes of older NUTS versions. |
| `time_period` | INTEGER | Reference year. |
| `obs_value` | DOUBLE | Observation value in the unit given in config/datasets.yml. |
| `obs_flag` | VARCHAR | Eurostat observation status flag. |
| `flag_meaning` | VARCHAR | English meaning of the flag. |
| `has_break` | BOOLEAN | Break in time series. |
| `is_estimated` | BOOLEAN | Estimated value. |
| `is_provisional` | BOOLEAN | Provisional value. |
| `is_low_reliability` | BOOLEAN | Low reliability value. |
| `source_last_update` | TIMESTAMP | Last update of the source dataset at Eurostat. |

## `staging.stg_eurostat__observations`

Typed observations of all configured indicators, one row per indicator, geo and year.

| Column | Type | Description |
|---|---|---|
| `indicator_id` | VARCHAR | Indicator identifier from config/datasets.yml. |
| `dataflow` | VARCHAR | Eurostat dataflow the row comes from (e.g. ESTAT:NAMA_10R_2GDP). |
| `geo` | VARCHAR | Eurostat GEO code (country, NUTS region or aggregate). |
| `time_period` | INTEGER | Reference year. |
| `obs_value` | DOUBLE | Observation value; null when Eurostat publishes no value. |
| `obs_flag` | VARCHAR | Eurostat observation status flag, possibly combined (e.g. "bep"). |
| `has_break` | BOOLEAN | True when the flag contains "b" (break in time series). |
| `is_estimated` | BOOLEAN | True when the flag contains "e" (estimated). |
| `is_provisional` | BOOLEAN | True when the flag contains "p" (provisional). |
| `is_low_reliability` | BOOLEAN | True when the flag contains "u" (low reliability). |
| `source_last_update` | TIMESTAMP | Last update of the dataset at Eurostat, from the SDMX-CSV "LAST UPDATE" column. |
